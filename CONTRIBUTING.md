# Contributing

Thanks for your interest in improving JobBoard.

## Before you start

- Check existing issues to avoid duplicate work.
- For large changes, open an issue first and describe the problem.
- Keep changes focused and explain why they help users.

## Development

This project uses plain HTML, CSS and JavaScript. Open `index.html` in a browser to test it. No package installation is needed.

## Pull requests

Please include:
- A clear summary of the change
- The reason for the change
- Steps you used to test it
- Screenshots for visible interface changes, when useful

Do not add private information or unverified real job listings.
