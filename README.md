# JobBoard — Job Search Website (Beginner Project)

A small, responsive job-board demo built with plain HTML, CSS and JavaScript. It demonstrates searching and filtering a list of sample jobs by keyword, location and category.

## Important: sample project, not a real vacancy service

All company names and job listings in this repository are fictional demo data. Do not present them as real vacancies. Verify employer details and obtain permission before publishing real listings.

## Features

- Responsive layout for desktop and mobile
- Search by title, company, location, category or description
- Filter by location and category
- Clear all filters
- Accessible labels and live result-count announcements
- No build tools or external dependencies

## Run it locally

1. Download or clone this repository.
2. Open `index.html` in a modern web browser.
3. Try searching for `sales`, or filter by `Jaipur` and `Sales`.

No installation is required.

## Project files

- `index.html` — page structure
- `styles.css` — layout and visual styling
- `script.js` — sample data, filters and rendering

## How to customise

Open `script.js` and edit the `jobs` array. Each job has:

- `title`
- `company`
- `location`
- `category`
- `type`
- `salary`
- `description`

Only add real job listings when you can verify that they are current and authorised for publication.

## Learning roadmap

1. Change the page title and colours.
2. Add two fictional sample jobs and test the filters.
3. Add a new filter, such as job type.
4. Add automated tests and document how to run them.
5. Invite feedback and review contributions responsibly.
